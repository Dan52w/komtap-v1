# Komtap

Sistema de gestión para tienda de ropa: proveedores, compras, inventario, ventas (POS),
gastos operativos, contabilidad y reportes. Construido con Tauri + React + TypeScript,
100% offline con SQLite local (HU-10).

## Módulos
1. Proveedores y Compras de Mercancía
2. Catálogo e Inventario de Prendas
3. Ventas y Caja (POS)
4. Contabilidad, Flujo de Caja y Reportes PDF
5. Operatividad Offline
6. Licenciamiento y Autenticación
